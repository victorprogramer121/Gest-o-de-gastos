# Sistema de gestão de gastos

O nosso banco de dados terá as tebelas: usuário, categoriaGasto, gastos, fatura


Usuario terá como atributo:
- id
- email
- senha

categoriaGasto terá como atributo:
- id
- nomeCategoria

gastos terá como atributo:
- id
- nomeGasto
- dataGasto
- valor
- idCategoria
